01

NucleoTech

Plataforma web de conversão e processamento de arquivos: ferramentas de imagem e áudio, contas, planos e pagamentos.

  • Python
  • Django
  • Django REST
  • JWT
  • Celery
  • Redis
  • Stripe
  • JavaScript

Repositório no GitHub

Problema
Reunir em um só lugar ferramentas de edição de imagem e conversão de áudio, com contas de usuário, planos de assinatura e limites de uso.
Minha contribuição
Autor de 30 dos 37 commits do repositório, em equipe: rotas, modelos e configuração do Django, ampliação dos webhooks do Stripe, permissões personalizadas, downloads seguros, histórico de pagamentos, auditoria de segurança e reestruturação do front-end.
Funcionalidades implementadas
Cadastro, login e renovação de token (JWT); perfil e painel de uso; planos com cotas diária e mensal; checkout, portal de cobrança e webhooks do Stripe; histórico de pagamentos; remoção de fundo, ampliação, conversão e miniaturas de imagens; conversão de áudio com FFmpeg; acompanhamento do status da tarefa; histórico de execuções; download seguro.
Desafios técnicos
Tirar o processamento pesado da requisição HTTP com tarefas Celery, aplicar limites por plano antes de processar, proteger o download dos resultados e revisar a segurança do próprio código.
Observação
Por padrão, as tarefas rodam em modo eager (síncrono). Com o Redis configurado como broker, o Celery as executa em segundo plano. O banco padrão é SQLite, trocável por variáveis de ambiente.

02

Jogos em Python

Flappy Bird e Dino (Chrome) em Pygame, cada um com versão jogável e versão controlada por uma IA treinada com NEAT.

  • Python
  • Pygame
  • NEAT

Repositório no GitHub

Minha contribuição
Projeto individual: todos os commits do repositório são meus.
Como a IA aprende
Uma população de 50 redes joga ao mesmo tempo. Cada rede recebe 3 entradas e decide quando pular. A pontuação (fitness) define quais redes se reproduzem e sofrem mutações, e o treino roda por 50 gerações. O NEAT evolui os pesos e também a estrutura da rede.
Desafios técnicos
Comportamento inesperado: a rede explorou uma brecha, dando micro-pulos a cada quadro em vez de pulos únicos como um jogador, e passava pelos canos com facilidade.

Renassol

Projeto acadêmico (PI2, 2025): loja virtual de placas solares fotovoltaicas, com conteúdo explicativo sobre energia solar.

  • React
  • Flask
  • MySQL
  • SQLAlchemy

Repositório no GitHub

Contexto
Trabalho em grupo da disciplina Projeto Integrador 2. A proposta combina a venda de placas e componentes com páginas sobre o funcionamento das placas, seus componentes e o descarte.
Minha contribuição
Back-end em Flask (configuração, modelos, rotas de usuários, produtos, carrinho e pedidos) e, no front-end React, cadastro, login, área do usuário e a integração da loja com a API.
Arquitetura
Interface React (Vite e React Router) que consome a API Flask por HTTP. O Flask usa SQLAlchemy sobre um banco MySQL com as tabelas de usuários, produtos, carrinhos e pedidos.
Estado
Projeto acadêmico encerrado, sem versão em produção.

IELB Charrua

Site de uma organização local, desenvolvido, publicado e mantido por mim desde 2026.

  • HTML
  • CSS
  • JavaScript

Acessar o site

Contexto e problema
Dar à comunidade um site simples de usar, com calendário, mensagens em áudio e contato direto. O público é majoritariamente idoso, o que orientou um design mobile-first e interações claras.
Minha contribuição
Implementação, hospedagem e manutenção contínua. Uso de API própria servida pela Cloudflare.
Funcionalidades
Site estático com várias páginas; calendário alimentado por arquivo JSON; player de mensagens em áudio no navegador; botão de contato que abre o WhatsApp.
Arquitetura
Páginas estáticas entregues ao navegador, com dados do calendário em JSON e uma API própria servida pela Cloudflare. O detalhamento da configuração dos serviços ainda precisa ser documentado.
